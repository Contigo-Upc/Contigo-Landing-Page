# Contigo - Landing Page

Landing Page de **Contigo**, una aplicación que guía paso a paso a adultos mayores y a personas con poca experiencia digital para realizar trámites y pagos en línea.

## Tecnologías

- HTML5
- CSS3
- JavaScript

## Estructura

```
index.html
assets/
  styles/main.css
  scripts/main.js
```

## Cómo ejecutarlo

Abre `index.html` en el navegador. No requiere instalación.
